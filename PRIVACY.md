# Privacy policy: EBS Longform Uploader

EBS Longform Uploader is a private tool used only by the owner of the YouTube channel
[Explained by Simulation](https://www.youtube.com/@ExplainedBySimulation) to upload that channel's own videos.

- **Who uses it:** only the channel owner. It is not offered to anyone else.
- **What it accesses:** with the owner's permission, it uploads videos, thumbnails and captions to the owner's own
  YouTube channel through the YouTube Data API. It does not read, collect or share any other Google account data.
- **What it stores:** one OAuth refresh token, kept as an encrypted GitHub Actions secret so the uploads can run
  automatically. No personal data about viewers or anyone else is collected or stored.
- **Sharing:** nothing is sold or shared with third parties.
- **Removing access:** the owner can revoke access at any time at https://myaccount.google.com/permissions.

Its use of information received from Google APIs follows the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

Contact: open an issue on this repository.
